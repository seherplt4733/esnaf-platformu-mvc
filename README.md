# Esnaf Platformu

Küçük işletmelerin kendi tanıtım sitelerini oluşturup yayınlayabileceği
bir ASP.NET Core MVC uygulaması.

İlk örnek işletme: Limon & Kekik.

## Yerelde çalıştırma

`dotnet run --project src/EsnafPlatformu.Web`
